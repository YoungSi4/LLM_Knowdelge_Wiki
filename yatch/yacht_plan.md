# Yacht Dice Game Plan (Refined & Enhanced)

## 1. 게임 룰 요약 (Game Rules)
Yacht(야추)는 5개의 주사위를 사용하여 정해진 카테고리의 점수를 채워 나가는 전략 보드게임입니다.

### 기본 흐름
- 총 12번의 라운드로 진행됩니다 (모든 카테고리를 채우면 종료).
- 각 라운드마다 플레이어는 최대 3번까지 주사위를 굴릴 수 있습니다.
  - 첫 번째 투구: 5개의 주사위를 모두 굴립니다.
  - 두 번째/세 번째 투구: 원하는 주사위는 남겨두고(Keep) 나머지만 다시 굴릴 수 있습니다.
- 주사위 굴리기가 끝나면(혹은 도중에) 반드시 하나의 점수 카테고리를 선택하여 점수를 기록해야 합니다.
- 한 번 기록된 카테고리는 수정할 수 없습니다.

### 점수 카테고리 및 세부 규칙 (Scoring Details)
| 카테고리 | 점수 계산 방식 | 불만족 시 처리 |
| :--- | :--- | :--- |
| **Aces ~ Sixes** | 해당 숫자 주사위의 총합 | 0점 (해당 숫자가 없는 경우) |
| **Subtotal Bonus** | Aces~Sixes 합계 ≥ 63점 이면 +35점 | 자동 계산 및 합산 |
| **Choice** | 모든 주사위 눈의 총합 | 항상 합계 점수 부여 |
| **4 of a Kind** | 같은 눈 4개 이상 시 모든 주사위 합 | 0점 (조건 미달 시) |
| **Full House** | 같은 눈 3개 + 2개 구성 시 모든 주사위 합 | 0점 (Yacht도 Full House로 인정) |
| **S. Straight** | 4개 이상의 연속된 숫자 포함 시 15점 | 0점 (예: 1-2-3-4, 2-3-4-5, 3-4-5-6) |
| **L. Straight** | 5개의 모든 숫자가 연속된 경우 30점 | 0점 (예: 1-2-3-4-5, 2-3-4-5-6) |
| **Yacht** | 5개의 주사위 눈이 모두 같을 때 50점 | 0점 (불일치 시) |

## 2. 정교한 로직 설계 (Advanced Logic Design)

### 2.1 주사위 고정 (Dice Holding) 로직 강화
- **입력 형식 및 파싱 (Input Parsing)**:
  - 사용자로부터 주사위 위치(1~5번)를 공백이나 쉼표로 구분하여 입력받습니다. (예: `1 2 5` 또는 `1,2,5`)
  - **정규식(Regex) 활용**: 입력 문자열에서 숫자만 추출하여 리스트로 변환합니다.
- **철저한 검증 (Strict Validation)**:
  - **범위 초과**: 1~5 이외의 숫자가 포함된 경우, 해당 숫자만 무시하거나 전체 재입력을 요구합니다.
  - **중복 입력**: 사용자가 `1 1 2`를 입력하더라도 내부적으로는 `set`을 사용하여 `{1, 2}`로 처리합니다.
  - **비정상 문자**: 문자가 섞여 있어도 숫자만 골라내거나, 아예 잘못된 형식임을 안내합니다.
- **토글(Toggle) 방식 지원**:
  - 현재 고정된 주사위 번호를 보여주고, 입력한 번호의 상태를 반전(Toggle)시키는 방식을 고려합니다. (이미 고정된 번호를 다시 입력하면 해제)
- **상태 시각화**:
  - 고정된 주사위는 `[ 5 ]`와 같이 별도의 표시(예: 괄호, 색상, 기호)를 통해 명확히 구분합니다.

### 2.2 점수 계산 및 예외 처리 (Score Calculation & Exception Handling)
- **전략적 0점 처리 (Strategic Zeroing)**:
  - 만족하는 족보가 없더라도 반드시 한 칸을 채워야 하므로, 0점이 기록되는 상황을 자연스럽게 유도하고 확인 절차를 거칩니다.
- **중복 기록 방지 (Duplicate Entry)**:
  - 이미 값이 입력된(0점 포함) 카테고리 인덱스를 선택할 경우, "이미 점수가 기록된 카테고리입니다. 다른 카테고리를 선택해주세요." 메시지를 출력하고 재입력 루프를 유지합니다.
- **판정 로직의 견고함 (Robust Judging)**:
  - **Straight**: 중복된 눈이 있는 경우(예: `1 2 2 3 4`)에도 정렬 및 중복 제거(`set`) 후 연속성을 체크하여 `S. Straight` 판정에 오류가 없도록 합니다.
  - **Full House**: 단순히 3개/2개 묶음뿐만 아니라, `Yacht`(5개 동일) 상황에서도 `Full House` 점수를 획득할 수 있도록 로직을 구성합니다.
- **실시간 점수 프리뷰 (Live Preview)**:
  - 현재 주사위로 얻을 수 있는 각 카테고리별 예상 점수를 점수판 옆에 나란히 출력하여 사용자의 실수를 방지합니다.

## 3. 프로그램 구조 및 인터페이스 (Program Structure)

### 3.1 `YachtGame` 클래스 상세
- `keep_status`: `[False, False, False, False, False]` 형태의 불리언 리스트로 고정 상태 관리.
- `roll_dice()`: `keep_status`가 `False`인 인덱스의 주사위만 `random.randint(1, 6)`으로 갱신.
- `update_keep(input_str)`: 입력받은 문자열을 파싱하여 `keep_status` 업데이트.
- `validate_category(choice)`: 사용자가 선택한 카테고리 번호가 유효한지(1~12 범위 내, 미기록 여부) 검사.
- `calculate_potential_scores()`: 현재 주사위 배열을 입력받아 12개 카테고리의 가능한 점수를 리턴.

### 3.2 주요 예외 상황 대응 시나리오
1. **잘못된 입력 처리**: `input()` 호출 시 `try-except` 블록으로 감싸 `ValueError` 등을 처리하고 무한 루프로 유효한 값을 받을 때까지 반복.
2. **강제 종료**: 사용자가 `exit` 또는 `quit` 입력 시 게임을 안전하게 종료하고 현재까지의 성적 출력.
3. **보너스 자동 달성**: `Aces~Sixes` 기록 시마다 합계를 체크하여 63점 돌파 즉시 보너스(+35) 점수를 점수판에 반영.
4. **결과 화면**: 12라운드 종료 후 총점과 함께 최고 점수(High Score) 달성 여부 등을 출력하여 성취감 고취.
