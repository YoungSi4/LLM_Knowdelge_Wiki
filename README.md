# Agentic LLM Wiki Platform

처음 보는 사람도 30분 안에 레포지토리를 클론하고 자신의 자료를 넣어 **나만의 지식베이스(LLM Wiki)**를 구축할 수 있도록 만들어진 완전한 패키지입니다. 
본 프로젝트는 **MCP(Model Context Protocol) 서버**와 **Conductor 패턴**을 결합하여, 할루시네이션(거짓 정보) 없이 안전하게 마크다운 지식을 업데이트하고 시각화할 수 있습니다.

## 🚀 30분 퀵스타트 가이드

### 1. 설치 및 환경 구성 (의존성)
1. Python 3.10 이상이 설치된 환경을 준비합니다.
2. 터미널(또는 명령 프롬프트)을 열고 필수 패키지를 설치합니다:
   ```bash
   pip install streamlit mcp
   ```

### 2. 패키지 구조 
- `raw/`: 사용자의 원본 자료(PDF, Text 등)를 임시 보관하는 폴더입니다.
- `wiki/`: 에이전트가 변환한 고밀도 마크다운 문서가 저장되는 핵심 지식베이스 폴더입니다.
- `tools/`: MCP 서버 스크립트(`mcp_server.py`)가 위치합니다.
- `harness/` & `schema/`: 시스템 에이전트 운영 규칙(`RULES.md`) 및 위키 도메인 제약 조건이 명세되어 있습니다.

### 3. 자료 투입 및 통합 요청 (사용법)
1. 학습하고 싶은 원본 문서를 `raw/` 디렉토리에 복사합니다.
2. 터미널에서 다음 명령어를 실행하여 웹 애플리케이션(UI)을 구동합니다:
   ```bash
   streamlit run app.py
   ```
3. 브라우저 창(`http://localhost:8501`)이 열리면, 우측의 **Conductor Chat** 패널에 다음과 같이 입력합니다.
   > *"raw 폴더에 있는 자료를 바탕으로 '새로운개념' 문서를 작성해 줘"*
4. Conductor(메인 에이전트)가 의도를 파악하고, 위키에 작성할 내용의 초안을 요약하여 보여줍니다 **(Draft Preview 사전 보고)**.
5. 내용을 확인한 후 이상이 없다면 **[✅ Approve]** 버튼을 누릅니다.
6. 백그라운드에서 `tools/mcp_server.py`의 `update_page` 도구가 원자적 파일 쓰기(Atomic Write)로 문서를 안전하게 추가합니다.
7. 좌측 **Wiki Explorer** 패널에서 드롭다운을 열어 새로 생성된 문서를 즉시 확인할 수 있습니다!

## 🛠 MCP Tool 목록과 동작 원리
본 패키지(`tools/mcp_server.py`)는 공식 파이썬 `mcp` SDK (FastMCP)를 통해 3가지 핵심 도구를 제공합니다.

1. `search_wiki(keyword)`: `wiki/` 폴더 내 모든 `.md` 파일을 순회하며 키워드를 검색하고 관련된 파일 목록과 링크를 반환합니다. (주로 QA 에이전트가 활용)
2. `read_page(page_name)`: 특정 파일(`[[문서명]]`)의 전체 텍스트 내용(Context)을 불러와 LLM에게 전달합니다.
3. `update_page(page_name, content)`: 새로운 지식을 작성할 때, 파일 오염을 방지하기 위해 먼저 임시 파일(`.tmp.md`)에 작성한 뒤 완료 시 원본으로 변경하는 Atomic Write 로직이 포함된 안전한 쓰기 도구입니다.

## ✅ 검증 방법 (Verification)
설치 및 구축이 정상적으로 완료되었는지 확인하려면 다음 절차를 따르세요.
1. 우측 챗봇 패널에 "ECS 아키텍처에 대해 요약해 줘" 등의 질문을 던져봅니다.
2. 챗봇이 `[[문서명]]`과 같은 명확한 출처 태그를 달아 답변한다면 `search_wiki` 및 `read_page` MCP 도구가 정상 작동하는 것입니다.
3. 새로운 지식을 추가(Approve)한 뒤, `wiki/` 로컬 폴더를 열었을 때 `.tmp.md` 형태의 찌꺼기 파일이 남아있지 않고 제대로 된 `.md` 파일이 존재하는지 확인합니다.
