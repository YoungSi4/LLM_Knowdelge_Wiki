# 프로젝트 사양서 (PRD) 및 에이전트 스펙

## 1. 프로젝트 개요 (Overview)
본 프로젝트는 **게임 개발 및 데이터 지향 설계(DOD)** 도메인 지식을 관리하고 학습하기 위한 **MCP 서버 기반의 지능형 Wiki Tool**을 구축하는 것을 목표로 합니다.
단순한 마크다운 문서 뷰어를 넘어, AI 에이전트(Conductor 및 Sub-agents)가 사용자와 상호작용하며 능동적으로 지식을 검색하고, 스스로 위키를 업데이트하는 시스템을 제공합니다.

## 2. MVP UI/UX 디자인 (Streamlit 기반 시각화)
시스템은 접근성과 확장성이 뛰어난 Python Streamlit 프레임워크를 기반으로 개발되며, 화면은 두 개의 주요 패널로 분할됩니다.
- **[Left Panel] 위키 탐색기 (Wiki Explorer):**
  - 현재 구축된 마크다운 기반의 위키 문서 목록(ECS, Cache Locality 등) 사이드바.
  - 선택한 문서의 내용을 렌더링하여 보여주는 메인 뷰어.
- **[Right Panel] 에이전트 대화창 (Conductor Chat):**
  - 사용자가 지식에 대해 질문하거나 새로운 지식 추가를 지시할 수 있는 대화형 인터페이스.

## 3. 핵심 시스템 아키텍처 (Conductor Pattern)
본 시스템은 단일 에이전트가 모든 것을 처리하는 구조를 탈피하여, 메인 에이전트(Conductor)가 목적에 맞는 서브 에이전트를 조율(Routing)하는 아키텍처를 채택했습니다.

### 3.1 사용자 의도 분류 및 라우팅
1. **단순 조회 (QA):** 사용자의 지시가 위키 내용 검색일 경우 `QA Agent`를 호출.
2. **지식 업데이트 (Build):** 새로운 지식 추가/수정 지시일 경우 `Planner Agent`와 `Writer Agent`를 순차 호출.

### 3.2 할루시네이션 방지 및 사전 검증 (Approval Report)
에이전트가 대화 중 도출된 정보나 잘못된 지식을 위키에 무단으로 작성하는 것을 방지합니다. 이를 위해 단순한 승인(Yes/No)이 아닌 **'사전 보고(Draft Preview)'** 절차를 거칩니다.
1. 사용자가 지식 추가를 요청하면, Conductor는 먼저 `Planner Agent`를 통해 **어떤 내용을, 어느 문서에, 어떤 형태로 추가할 것인지** 초안(Report)을 작성하게 합니다.
2. Conductor는 이 초안을 채팅창을 통해 사용자에게 먼저 보여줍니다.
3. 사용자가 추가될 내용을 직접 확인하고 최종 승인(Approve)을 내렸을 때만, 비로소 `Writer Agent`를 호출하여 실제 파일 쓰기를 진행합니다.

### 3.3 에러 롤백 및 원자성 (Atomicity) 보장
파일 쓰기 도중 프로세스가 중단되어 문서가 훼손되는 것을 방지하기 위해, Writer Agent는 항상 `.tmp.md` 형태의 임시 파일에 먼저 작성합니다. 작성이 무사히 완료된 경우에만 원본 파일을 덮어쓰며, 에러 발생 시(`[ERROR_SIGNAL]`) 롤백합니다.

## 4. 에이전트 명세서 (Agent Specifications)

### 4.1 메인 에이전트 (Conductor)
- **역할:** 사용자와 직접 대화하며 의도를 파악하고 시스템을 조율하는 지휘자.
- **권한:** 문서 내용 직접 수정 불가. 오직 Sub-agent들을 서브프로세스로 호출(위임)할 권한만 가짐.

### 4.2 Planner Agent (`wiki_planner.json`)
- **역할:** 새로 추가될 정보나 원시 텍스트(Raw data)를 분석하여 위키 구조(목차, 연결성)를 설계.
- **권한:** `./raw/` 폴더에 대한 읽기 전용(Read-only).

### 4.3 Writer Agent (`wiki_writer.json`)
- **역할:** Planner의 설계를 바탕으로 실제 마크다운 위키 페이지를 작성하고 타 문서와의 링크(`[[...]]`)를 생성.
- **권한:** `./wiki/` 폴더에 대한 쓰기(Write) 권한 (원자성 규칙 준수 필수).

### 4.4 QA Agent (`wiki_qa.json`)
- **역할:** 사용자 질문에 대해 기존 위키 문서들을 검색하여 정확한 답변을 제공.
- **권한:** `./wiki/` 폴더에 대한 읽기/검색 전용(Read/Search-only). 반드시 `[[문서명]]` 형식으로 출처 표기 의무.
